---
name: mvp-flow
description: Flujo MVP de Santi. Úsalo al empezar una feature o idea nueva.
disable-model-invocation: true
---
1. Idea difusa: /grill-me (o /grill-with-docs si ya hay código).
2. Duda de UX o de lógica: skill prototype (desechable).
3. ¿Cabe en una sesión? Entonces /implement. Si no: /to-spec, /to-tickets, /clear y /implement por ticket.
4. Antes de enseñar la demo: /code-review. Tras una sesión mala: /retro.
