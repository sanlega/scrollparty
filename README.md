# ScrollParty

Tus amigos van metiendo reels, TikToks y Shorts en una bolsa compartida. Cuando quedáis, ponéis la
sesión en la tele y adivináis quién mandó cada uno. Ranking y premios al final.

- Spec de producto: [docs/spec/producto.md](docs/spec/producto.md)
- Decisiones: [docs/decisiones/](docs/decisiones/)
- Contexto para agentes: [AGENTS.md](AGENTS.md)

Apps nativas: iOS (SwiftUI) y Android (Jetpack Compose), backend Firebase.
